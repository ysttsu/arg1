1) index.html（TOP）

タイトル
	•	TITLE: ＊個人サイト＊（復旧ログ）

見出し
	•	H1: ＊ようこそ＊

冒頭テキスト（常時）
	•	P: 昔の個人サイトのアーカイブです。
	•	P: リンク切れとか、たまにあります。
	•	P: （ゆっくり直します）

カウンター表記（任意・世界観用、進捗ではない）
	•	SMALL: あなたは【${visits}】人目のお客さん

MENU（“増える”）

ここが「気づいたら増えている」のメイン。
初期は最低限、条件達成で項目が増える。

MENU見出し（常時）
	•	H2: ★MENU★

初期（常時）
	•	LINK: 自己紹介 → profile.html
	•	TEXT(補足): （とりあえず）

frag_profile 取得済みで追加
	•	LINK: 日記 → diary.html
	•	TEXT(補足): （たまに更新）

frag_diary 取得済みで追加
	•	LINK: リンク → links.html
	•	TEXT(補足): （巡回用）

frag_links 取得済みで追加
	•	LINK: 掲示板 → bbs.html
	•	TEXT(補足): （ログ）

frag_bbs 取得済みで追加（※露骨にしない）
	•	LINK: 倉庫 → secret.html
	•	TEXT(補足): （古いメモ）

frag_secret 取得済みで追加（※露骨にしない）
	•	LINK: 完成ページ → ending.html
	•	TEXT(補足): （たぶん）

“自然なリンク切れ”（404踏ませる）

露骨な説明は不要。個人サイトあるあるで踏ませる。

	•	H2: ★おまけ★
	•	LINK(壊れてる): キリ番報告はこちら → kiriban.html（存在しないURL）
	•	TEXT: 踏み逃げ禁止（嘘）
	•	LINK(壊れてる): 素材置き場 → sozai.html（存在しないURL）

9) robots.txt（任意）

secretを補助的に“匂わせたい”場合のみ。必須ではない。

案A：使う
```
User-agent: *
Disallow: /arg1/secret.html
```

案B：使わない（推奨寄り）
	•	404導線を「リンク切れ」で十分踏ませるなら robots.txt は不要

Codex実装の注意（台本適用時）
	•	文章をそのまま固定で入れつつ、差分は DOM差し替えで実現する
	•	indexのMENUはJSで生成（条件で項目を追加）
	•	profileはLIの中身を条件で差し替え
	•	diary/links/bbsはブロックを条件で追加
	•	条件不足アクセス時は 黙ってindexへ location.replace（テキスト表示しない）
